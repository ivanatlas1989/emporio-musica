Repositório criado para desenvolvimento e entrega do desafio do processo seletivo da empresa Artfact.
O desafio: Empório da Música é uma loja fictícia de instrumentos musicais localizada em Campo Grande/MS. Hoje, o atendimento é inteiramente realizado pela equipe, que está sobrecarregada com perguntas recorrentes: horários de funcionamento, status de pedido, preço e disponibilidade de produtos, etc.
Devemos: prototipar um agente de atendimento que irá auxiliar a equipe no atendimento. Para isso, a loja forneceu os seguintes materiais para uso do agente:
Tabelas com dados da operação, como produtos, pedidos, clientes e promoções.
Manual interno de políticas e procedimentos de atendimento ao cliente.
